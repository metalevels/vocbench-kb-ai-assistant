# VocBench Knowledge Chat – README

This repository contains the project documentation and architecture for building a conversational assistant capable of chatting with the knowledge extracted from the VocBench Google Group.

The system leverages:
- **Anthropic SDK** for LLM-based conversational interactions.
- **Scraping pipeline** for extracting content from the public VocBench Google Group archive.
- **Vector-based retrieval layer** for semantic search and contextual retrieval.

Refer to `PROJECT_OVERVIEW.md` for objectives and system design, and `DEV_GUIDE.md` for technical implementation instructions.
